## Prior art

The two-hand framing gesture was popularised in the browser by
[sophiamyang/finger-frame-effect](https://github.com/sophiamyang/finger-frame-effect)
and its siblings. Those repositories carry **no licence**, so no code from them
is used here; the implementation in `scripts/tracking/frame-quad.ts` and
`scripts/render/shaders/portal.ts` is independent, and it is credited here
because the gesture and the problems it raises are theirs to have found first.

The approaches differ in what performs the stylisation:

| Project | Interior generated by | Latency | Cost |
|---------|----------------------|---------|------|
| `finger-frame-effect` | Canvas 2D effects | none | free |
| `finger-frame-effect-ai` | Gemini Omni Flash, on an uploaded clip | minutes | paid, user's own key |
| `finger-frame-effect-lucy` | Decart Lucy 2.5, live | near real time | paid |
| **GESTURE-FX** | **A WebGL cel-shade shader** | **none** | **free** |

A generative model produces a genuinely different subject; a shader restyles the
subject that is there. The shader was chosen because this project's founding
constraint is that it runs with no key, no server and no per-use cost, and that
constraint is worth more here than the extra fidelity.

## What is deliberately absent

No analytics, no telemetry, no error reporting service, no font network, no
content delivery network for application code, no cookies, no service worker
that phones home, and no backend of any kind. The consequence is stated plainly
in [PRIVACY.md](PRIVACY.md): after the first load, the application works with
the network switched off.
